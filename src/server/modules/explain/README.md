# Brique Explain

## Rôle
Fournit le glossaire et les textes explicatifs en français naturel pour chaque écran du dashboard.

## Entrées
- Clé du glossaire et paramètres dynamiques du restaurant.

## Sorties
- Infobulles pédagogiques (`HelpTerm`) et volets déroulants de calcul pas à pas (`HowItsCalculated`).

## Règles
1. Zéro jargon technique : tout doit être immédiatement compréhensible par un restaurateur débutant.
2. Toutes les phrases de calcul intègrent les vrais chiffres de l'établissement.
